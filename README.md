# CYBER HAYAT PK

**Digital Safety • Support • Awareness**

Offline-first Flutter Android companion for digital-safety incidents in Pakistan.

Core guidance, assistant, evidence vault, cases, checklists, legal awareness, and helpline directory work without internet. The app never claims a call, complaint, or sync succeeded unless it actually did.

See `CyberHayatPK_Offline_Mobile_README.md` for the product specification and `docs/BUILD.md` for build instructions.

## Privacy
No advertising SDKs. No hidden tracking. Passwords are never requested. Chats stay on-device unless the user exports them.
